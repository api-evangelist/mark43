# Mark43

> Mark43 is a cloud-native public safety software company. Its platform unifies computer-aided dispatch (CAD), records management (RMS), first-responder mobile apps, evidence and property management, and analytics for more than 300 law enforcement and public safety agencies. The Mark43 Partnerships (External) API lets approved technology partners integrate directly with an agency's Mark43 tenant.

## API
- Name: Mark43 Partnerships API
- Base URL: https://department.mark43.com/partnerships/api (per-agency subdomain)
- Auth: HTTP Basic Authorization header with an agency-issued secure API token
- Format: JSON (UTF-8); responses wrapped in a `{ data, success, error }` envelope
- Status codes: RFC 2616 / RFC 6585 (429 for rate limiting)

## Endpoint families (100 operations)
- Reports — arrest, offense, traffic crash, tow vehicle, supplement, field contact, missing person, citation, custom (single + bulk), release, histories
- Persons — master person, search, attributes, identifying marks, name identifiers, merge
- Evidence — items, import events, chains of custody, chain events
- Attachments — files, images, search, streaming
- CAD — events (create, scheduled, additional info), configuration (units, stations, unit states/statuses), tickets, phone calls
- Warrants — search, status, numbers, activities
- Cases — list, updated, notes
- Users — list, full, ids, upsert, v2, with roles
- Tasks, Vehicles (search), Associated Records (external links), GPS, E911 (incl. NJ)
